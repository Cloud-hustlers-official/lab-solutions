# Create and Manage AlloyDB Instances: Challenge Lab (GSP395)

Automate the **Create and Manage AlloyDB Instances: Challenge Lab** on Google Cloud with a single command.

## 🚀 Run the Script

```bash
curl -LO "https://raw.githubusercontent.com/Cloud-hustlers-official/lab-solutions/refs/heads/main/Create%20and%20Manage%20AlloyDB%20Instances%3A%20Challenge%20Lab/cw-gsp395-script.sh" 
sudo chmod +x cw-gsp395-script.sh
./cw-gsp395-script.sh
```

## 📌 What the Script Does

- Auto-detects Project ID, Zone, and Region
- Creates an AlloyDB Cluster and Primary Instance
- Imports sample database schema and data
- Creates a Read Pool Instance
- Creates a Manual Backup
