## ✅ Task 2 — Managed Apache Spark Job

### Step 1 — Cluster banao (Cloud Shell)

```bash

export REGION=us-east1
export DATAPROC_CLUSTER=cluster-lab

gcloud dataproc clusters create $DATAPROC_CLUSTER \
  --region=$REGION \
  --zone=us-east1-c \
  --master-machine-type=n2d-standard-2 \
  --master-boot-disk-type=pd-standard \
  --master-boot-disk-size=100 \
  --worker-machine-type=n2d-standard-2 \
  --worker-boot-disk-type=pd-standard \
  --worker-boot-disk-size=100 \
  --num-workers=2
```

> ⏳ 3-4 min wait karo — RUNNING hone do

---

### Step 2 — HDFS mein data copy karo

**Option A — Cloud Shell se:**

```bash
MASTER_NODE=$(gcloud compute instances list \
  --filter="name ~ cluster-lab-m" \
  --format="value(name)")

MASTER_ZONE=$(gcloud compute instances list \
  --filter="name ~ cluster-lab-m" \
  --format="value(zone)")

gcloud compute ssh $MASTER_NODE --zone=$MASTER_ZONE --quiet \
  --command="hdfs dfs -cp gs://spls/gsp323/data.txt /data.txt"
```

**Option B — UI se (SSH):**
1. Navigation → Compute Engine → VM Instances
2. `cluster-lab-m` VM → **SSH** button click karo
3. Terminal mein run karo:
```bash
hdfs dfs -cp gs://spls/gsp323/data.txt /data.txt
```

---

### Step 3 — Spark Job submit karo (UI)

1. **Navigation → Dataproc → Jobs → Submit Job**
2. Fill karo:

| Field | Value |
|---|---|
| Region | `us-east1` |
| Cluster | `cluster-lab` |
| Job type | `Spark` |
| Main class | `org.apache.spark.examples.SparkPageRank` |
| Jar files | `file:///usr/lib/spark/examples/jars/spark-examples.jar` |
| Arguments | `/data.txt` |
| Max restarts/hr | `1` |

3. **Submit** click karo ✅

optional command
```
gcloud dataproc jobs submit spark \
  --cluster=$DATAPROC_CLUSTER \
  --region=$REGION \
  --class=org.apache.spark.examples.SparkPageRank \
  --jars=file:///usr/lib/spark/examples/jars/spark-examples.jar \
  -- /data.txt

```
4. Job finish hone ka wait karo
